The role of OKF and MCP

  1. 01

    Publish

    Describe authoritative sources, spatial meaning and access routes in a versioned OKF pack.

  2. 02

    Discover

    Use text, metadata facets and map context over one explainable result set.

  3. 03

    Bind

    Turn a chosen record into an explicit tool and argument contract.

  4. 04

    Execute

    Run the read-only operation through MCP, with credentials kept on the server.

  5. 05

    Audit

    Retain source, identifiers, arguments and outcome without overstating relationships.

Public by design

No API key enters this site.

GitHub Pages serves a deterministic, checked-in snapshot and a key-free map context. It can preview MCP requests but cannot execute OS calls. Live execution belongs on the MCP Geo server, where access, credentials and errors remain governed.
