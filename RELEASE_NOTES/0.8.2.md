# Release 0.8.2

Date: 2026-06-16

## Summary

`0.8.2` is a documentation, setup, and compatibility release. It adds a
complete full-spatial LandIS warehouse setup path, improves first-run OS Data
Hub and Docker guidance, records the MCP 2026 release-candidate alignment work,
and refreshes several research and compliance documentation surfaces.

## Added

- Full LandIS spatial warehouse setup guide for a PostGIS-backed MCP-Geo
  topology, including wrapper-managed bootstrap, archive validation, row-count
  checks, clean retests, and the criteria for a future separate LandIS MCP
  server.
- Public OS Data Hub first-run setup guide with secret-file and Docker STDIO
  smoke-test guidance.
- LLM-wiki postmortem workflow and public-safe MCP-Geo conversation wiki
  artifacts for the LandIS/LEACS and client-failure evidence threads.

## Changed

- Refreshed MCP 2026 release-candidate alignment docs and feature-gated runtime
  handling.
- Added OS NGD postcode-boundary BigQuery extract guidance, including CRS84
  versus EPSG:4326 axis-order notes.
- Added HTTP demo launcher documentation for Docker-backed HTTP MCP testing.

## Fixed

- Clarified MCP-App resource handoff behavior so clients preserve `ui://`
  resources.
- Refreshed OWASP MCP attestation evidence and stabilized wall-clock-sensitive
  validation fixtures.
- Repaired broken research-pack images and session-local citation handles.
- Corrected first-run Docker and `.env` setup pitfalls, including JSON-RPC IDs,
  quoted env values, secret mounts, OS Places entitlement, and LandIS PostGIS
  requirements.
