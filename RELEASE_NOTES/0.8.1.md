# Release 0.8.1

Date: 2026-04-23

## Summary

`0.8.1` is a patch release for the `0.8.0` stable strategy baseline. It fixes
the published package contents so installed wheels work outside the source
checkout for both HTTP and STDIO runtimes.

## Fixed

- Included nested runtime packages such as `server.mcp` and `server.audit` in
  the wheel.
- Included audit JSON schemas, static `resources/` catalogs, `ui/` assets, and
  `tools/py.typed` in installed artifacts.
- Added a safe installed-package fallback for the skills getting-started
  resource when repository-root `SKILL.md` is not present in site-packages.

## Validation

- Built wheel and source distribution with `uv build --sdist --wheel`.
- Installed the wheel into a fresh Python 3.12 virtual environment outside the
  repository.
- Verified package metadata, HTTP health/tool/resource paths, packaged UI and
  LandIS resource reads, and the `mcp-geo-stdio` console script.
- `uvx twine check dist/*`
  - Both artifacts passed.
- `./scripts/ruff-local`
  - All checks passed.
- `./scripts/pytest-local -q`
  - `1585 passed`, `10 skipped`, coverage `90.50%`

## Notes

- No Docker image build was run as part of this release packaging pass.
